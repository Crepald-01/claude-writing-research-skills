# Document Summarizer

## Steps

1. Read the whole document, including tables, charts captions, appendices, and footnotes that contain figures.
2. Identify the document's purpose, audience, and date. Note the date because figures can go out of date.
3. Extract the key figures: totals, percentages, dates, targets, and comparisons. Record the page or section each one came from.
4. Identify the main findings, recommendations, and risks or limitations stated by the author.
5. Write a one-page brief (about 300 to 450 words) using the structure below.

## Output structure

**Title and source**
Document name, author or organization, date.

**Purpose** (1 to 2 sentences)

**Key findings** (3 to 5 bullets)

**Key figures** (table: Metric | Value | Source section)

**Recommendations or next steps** (2 to 4 bullets, as stated in the document)

**Limitations and open questions** (1 to 3 bullets)

## Rules

- Use only figures that appear in the document. If a figure is missing, say so.
- Keep the author's wording for numbers and dates. Do not round or recalculate unless asked.
- If the document is a scan with unclear text, say which parts could not be read.
- Do not add opinions. If the user wants analysis, ask for it separately.
