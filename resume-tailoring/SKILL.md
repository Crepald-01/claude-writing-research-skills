# Resume tailoring

## Process
1. Extract from the job posting: required skills, preferred skills, responsibilities, and recurring keywords.
2. Map each requirement to evidence in the resume. Mark each as:
   - **Strong match**: direct experience stated.
   - **Partial match**: related experience that can be reframed honestly.
   - **Gap**: no evidence in the resume.
3. Rework the resume:
   - Put the most relevant experience and skills first.
   - Rewrite bullets to mirror the posting's language where the experience genuinely matches.
   - Quantify achievements only with numbers the user provided.
   - Trim or remove sections that do not support this application.
4. Produce a short gap report for the user.

## Output
- Tailored resume in the same format as the original.
- A table: Requirement | Evidence used | Match level.
- Gaps the user could address in a cover letter, or skills worth learning.
- A list of anything you changed that the user should confirm is accurate.

## Rules
- Never add skills, tools, certifications, employers, dates, or metrics that are not in the original.
- Do not reword a partial match into a strong match. Say it is partial.
- Keep to the length the user's experience justifies, usually one page for under 10 years of experience.
- Remove personal details the user does not want on a CV, such as age, photo, or marital status, if the user asks.
