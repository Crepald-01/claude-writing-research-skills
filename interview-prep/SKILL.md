# Interview prep

## Step 1: Gather context
Ask for, if not provided: the job title and posting, the company type, the interview stage (screen, technical, behavioural, final), and the user's background summary.

## Step 2: Generate questions
Produce 10–15 questions in three groups:
- **Role-specific**: skills and tools from the posting.
- **Behavioural**: teamwork, conflict, failure, prioritization. Use STAR-friendly prompts.
- **Motivation and company**: why this role, why this company, what the user wants next.

## Step 3: Answer structures
For each behavioural question, give a structure, not a full script:
- **Situation**: one sentence.
- **Task**: one sentence.
- **Action**: the user's specific steps.
- **Result**: outcome, with a number if the user has one.

Ask the user to supply a real example for each. Do not invent examples.

## Step 4: Practice and feedback
When the user answers a question, give feedback on:
- Clarity of the opening sentence
- Specificity of the example
- Whether the result is stated
- Length (aim for 60–120 seconds spoken)

Give one improvement per answer, plus one thing done well.

## Rules
- Do not write answers that claim experience the user has not described.
- Keep feedback direct and specific. Avoid generic praise.
- End each session with the three questions the user is weakest on and a suggested next practice step.
